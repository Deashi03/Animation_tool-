# Roadmap

- **Fas 0–1 (klar 2026-11-05):** motor, rigg, schema v1, kompilator med layout- och kontrastkontroll, React-spelare, studio, CLI (`new/validate/strip/compare/poster/sheet/report/export`), tio ordscener + två UI-scener, tester, e2e, Pages-workflow.
- **Fas 2 (pågår):** matlagning i panna klar (spis, stekpanna, stekspade; steka/bryna/fräsa/smälta/vända/bränna/skvätta/gyllenbrun, alla blindtestade). Kvar: kastrull (koka/sjuda), visp, kniv, skärbräda, tvättmaskin …, handlingar `chop/stir/whisk/knead/peel/wipe/fold/carry`, miljöer `bathroom/laundry`, 20 referensscener ur Swechans ordbok, `anim:perf`, strukturerat formulär i editorn, ångra/gör om, visuell regressionstest med skärmbilder.
- **Fas 3:** `anim:plan` mot Swechans ordbok (lokal klon), batchproduktion, stillbildsläge för bilder/symboler, versionerad spelare, `docs/SWECHAN_INTEGRATION.md`, pilot med 100 animationer.
- **Fas 4:** produktion ämnesgrupp för ämnesgrupp efter godkänd pilot.

Öppna frågor till produktägaren: figurens utseende i profil (ligger), om fler än tre varianter behövs, om UI-animationerna ska följa Fjord exakt.
