# Roadmap

- **Fas 0–1 (klar 2026-11-05):** motor, rigg, schema v1, kompilator med layout- och kontrastkontroll, React-spelare, studio, CLI (`new/validate/strip/compare/poster/sheet/report/export`), tio ordscener + två UI-scener, tester, e2e, Pages-workflow.
- **Fas 2 (pågår, 0.4.0):** generellt bibliotek klart i första version – verktyg/kärl/råvaror/inventarier/plagg, `use`/`say`/`give`/`dress`/`fasten`, processer utan människa; 75 scener. Kvar: `anim:batch`, täckningsrapport mot hela ordboken, `anim:perf`, strukturerat formulär. Matlagning i panna klar (spis, stekpanna, stekspade; steka/bryna/fräsa/smälta/vända/bränna/skvätta/gyllenbrun, alla blindtestade). Kvar: kastrull (koka/sjuda), visp, kniv, skärbräda, tvättmaskin …, handlingar `chop/stir/whisk/knead/peel/wipe/fold/carry`, miljöer `bathroom/laundry`, 20 referensscener ur Swechans ordbok, `anim:perf`, strukturerat formulär i editorn, ångra/gör om, visuell regressionstest med skärmbilder.
- **Fas 3 (påbörjad 0.5.0):** `anim:plan`, `anim:coverage`, `anim:batch`, `anim:perf`, `anim:package`, `docs/SWECHAN_INTEGRATION.md` klara. Kvar: femmodulspilot med blindtester och produktägarens stickprov, därefter 100-pilot; stillbildsläge för bilder/symboler; index per modul i exporten; lat laddning av föremålsfamiljer om spelarstorleken (61 kB gzip) blir ett problem.
- **Fas 4:** produktion ämnesgrupp för ämnesgrupp efter godkänd pilot.

Öppna frågor till produktägaren: figurens utseende i profil (ligger), om fler än tre varianter behövs, om UI-animationerna ska följa Fjord exakt.
